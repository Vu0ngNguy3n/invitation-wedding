# UI Specification

## Visual Identity

Primary:
- Vintage green
- Warm ivory
- Cream
- Muted light gold
- Kraft / paper neutrals

## Surfaces

Prefer:
- paper-like backgrounds
- subtle texture
- thin ornamental borders
- engraved/embossed visual hints
- botanical motifs

Avoid:
- glassmorphism
- neon gradients
- heavy shadows
- generic white cards on gray background
- excessive rounded corners

## Typography

Use an intentional pairing:
- Display serif / elegant serif for names and headings
- Refined readable serif or sans-serif for body copy

Typography must create hierarchy through:
- size
- weight
- letter spacing
- line height
- capitalization

Do not use too many font families.

## Buttons

Buttons should feel tactile and editorial:
- subtle border
- restrained fill
- clear focus state
- comfortable touch target
- icon optional

## Images

Prefer:
- framed photography
- editorial crops
- organic compositions
- paper/photo album treatments

## Borders and Decoration

Decorative elements should reinforce the invitation theme rather than become
visual noise.
