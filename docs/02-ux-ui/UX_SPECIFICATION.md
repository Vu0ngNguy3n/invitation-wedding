# UX Specification

## Overall Experience

The website behaves like a digital invitation, not an application.

The user should feel:
"mở thiệp" → "đọc câu chuyện" → "xem ngày cưới" → "xem ảnh" → "gửi lời chúc".

## Layout Philosophy

Use:
- generous whitespace
- editorial alignment
- asymmetry where intentional
- layered paper elements
- botanical framing
- subtle depth
- deliberate pacing between sections

Avoid:
- dense grids
- excessive cards
- dashboard sidebars
- generic CTA-heavy landing pages
- overly rounded SaaS components

## Section Rhythm

Sections should have visual breathing room.
Transitions may use:
- paper folds
- ornaments
- botanical dividers
- soft fades
- subtle parallax only where it improves the experience

## CTA Principles

CTAs should feel invitation-like:
- View Album
- Save the Date
- View Map
- Leave a Wish
- View Gift Information

Avoid aggressive conversion language.

## Mobile

Mobile is the primary interaction context.

Important:
- readable typography
- touch-friendly controls
- no tiny buttons
- no horizontal overflow
- gallery must be easy to browse
- guestbook form must be comfortable to use with a thumb
