# Design System

## Tokens

Create design tokens for:

### Color
- background
- surface
- primary green
- secondary green
- text
- muted text
- gold accent
- border
- success
- error

### Typography
- display
- heading
- body
- caption
- overline

### Spacing
Use a consistent spacing scale.

### Radius
Keep radius restrained. Avoid default SaaS-style pill shapes everywhere.

### Shadows
Use soft, low-contrast depth sparingly.

## Reusable Components

Expected foundation components:
- Section
- SectionHeading
- OrnamentalDivider
- PaperSurface
- DecorativeFrame
- PrimaryButton
- SecondaryButton
- ImageFrame
- Reveal
- IconButton
- Modal/Lightbox foundation

Feature components should be composed from these primitives where appropriate.

## Design Principle

Every component should look like it belongs to the same physical invitation.
