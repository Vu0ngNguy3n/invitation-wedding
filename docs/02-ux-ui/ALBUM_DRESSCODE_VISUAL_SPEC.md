# Album Slider + Dress Code — Visual Specification

## Album visual direction
Use the reference only for composition:
- large focal image
- slim left/right arrows
- thumbnail strip below

Translate it into the existing Fine-Art Botanical identity.

Main image:
- editorial
- strong focal scale
- no generic card chrome
- no heavy shadow/glass effect

Arrows:
- slim
- functional
- Vintage Green / Champagne Gold accent
- at least ~44px hit area
- Lucide ChevronLeft/ChevronRight if already used

Thumbnails:
- small rectangular editorial crops
- subtle gaps
- active state via Champagne Gold hairline and/or contrast
- minimal or no radius if consistent with current photography language
- mobile horizontal scrolling/snap

Transition:
- short crossfade
- optional 0.995 → 1 subtle scale
- 300–500ms
- no dramatic full-width movement

## Dress Code surface
Preferred:
- Warm Ivory `#FAF8F3`
- or Paper Cream `#F3EEE4`

Heading:
- current premium display serif
- Deep Forest / Vintage Green
- uppercase with refined tracking

Body:
- current readable body serif
- Deep Ink / Vintage Green
- centered

## Dress Code local palette
Beige: `#E9D8C6`
Pastel Pink: `#F1CDD3`
Pastel Blue: `#CFE1E8`

Recommended harmony:
- background → Warm Ivory / Paper Cream
- title → Deep Forest
- body → Deep Ink
- tiny divider → Champagne Gold
- swatches → Beige / Pastel Pink / Pastel Blue

These pastel colors are local to Dress Code only.

## Swatches
Three circles, slightly overlapping if elegant.

Responsive diameter guideline:
- mobile ~64–78px
- desktop ~76–96px

Optional:
- thin Warm Ivory/Soft White ring
- very subtle contact shadow

Avoid:
- glossy gradients
- metallic effects
- thick borders
- hover selection behavior
- ecommerce color-picker styling

## Spacing
Album thumbnails
→ generous breathing space
→ small ornament/title
→ swatches
→ copy
→ generous bottom padding

Use current spacing tokens.

Final feeling:
Album = curated wedding photo set.
Dress Code = small printed attire insert.
