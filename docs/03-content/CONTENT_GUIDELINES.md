# Content Guidelines

## Voice

The copy should feel:
- intimate
- warm
- elegant
- sincere
- concise

Avoid:
- marketing language
- corporate language
- generic inspirational filler
- excessive emoji use

## Names

Always use the exact configured couple names.

## Dates

Keep machine-readable ISO datetime values separate from display labels.

## Events

Use concise, guest-friendly wording.
Venue/address information should be scannable.

## Guestbook

Use a warm invitation to leave a message.
Validation messages should be polite and clear.

## Thank You

The closing should feel personal and grateful.
