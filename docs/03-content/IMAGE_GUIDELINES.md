# Image Guidelines

## Directory Recommendation

public/
└── images/
    ├── hero/
    ├── couple/
    ├── events/
    ├── gallery/
    └── gift/

## Naming

Use descriptive stable names:
- hero-desktop.webp
- hero-mobile.webp
- bride.webp
- groom.webp
- gallery-01.webp

Avoid:
- IMG_1234.jpg
- image-final-final2.jpg

## Quality

Prefer optimized:
- WebP
- AVIF where appropriate

Do not sacrifice visual quality for extreme compression.

## Accessibility

Every meaningful image needs meaningful alt text.
Decorative images should use empty alt text where appropriate.

## Performance

Hero images should be intentionally optimized because they affect LCP.
Gallery images should generally be lazy-loaded.
