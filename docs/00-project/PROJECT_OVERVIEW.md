# Project Overview

## Product

Premium online wedding invitation website.

## Experience Goal

Recreate the emotional feeling of opening and reading a beautifully crafted
physical wedding invitation, while adding digital capabilities such as:
- Countdown
- Calendar
- Interactive gallery
- Guestbook
- Maps
- Digital wedding gift QR codes

## Primary Audience

Wedding guests receiving a digital invitation link on mobile or desktop.

## Core Emotional Qualities

- Warm
- Intimate
- Romantic
- Refined
- Nostalgic
- Personal
- Celebratory

## Core Journey

1. Opening / Cover
2. Couple introduction
3. Save the Date
4. Countdown
5. Bride story
6. Groom story
7. Wedding events
8. Photo album
9. Guestbook
10. Wedding gifts / QR
11. Thank You

## Technical Direction

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- lucide-react
- Supabase
- Vercel

## Non-goals

The initial product is not:
- A wedding planning platform
- An admin dashboard
- A multi-tenant SaaS
- A full CMS
- A social network
- A payment system
