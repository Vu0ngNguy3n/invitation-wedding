# Deployment

## Target

Vercel for Next.js.

Supabase for PostgreSQL.

## Steps

1. Push repository to Git.
2. Create/configure Supabase project.
3. Apply database schema.
4. Apply RLS.
5. Configure Vercel environment variables.
6. Deploy.
7. Verify production guestbook.
8. Verify images and metadata.
9. Test mobile and desktop.
10. Connect domain if applicable.

## Production Requirements

- HTTPS
- production environment variables
- no secret in client bundle
- database accessible from server
- build passes
- guestbook tested
- SEO metadata checked
