# Definition of Done

A feature is Done only when:

## Functionality
- [ ] Requirement implemented
- [ ] Edge cases handled
- [ ] Loading/error/empty states considered

## Code
- [ ] TypeScript strict
- [ ] No unnecessary duplication
- [ ] Reusable architecture
- [ ] No avoidable `any`
- [ ] No unnecessary dependency

## UI/UX
- [ ] Mobile-first
- [ ] Desktop reviewed
- [ ] Typography follows system
- [ ] Colors follow system
- [ ] Decorative language is consistent
- [ ] Motion is subtle

## Accessibility
- [ ] Semantic HTML
- [ ] Keyboard interaction
- [ ] Focus state
- [ ] Labels
- [ ] Alt text
- [ ] Reduced motion

## Performance
- [ ] Images optimized
- [ ] Client boundary minimized
- [ ] No obvious layout shift
- [ ] No excessive animation

## Validation
- [ ] Typecheck
- [ ] Lint
- [ ] Build

## Documentation
- [ ] Relevant docs updated
- [ ] PROJECT_STATUS.md updated
