# Database Design

## Database

Supabase PostgreSQL.

## Entity: guestbook_wishes

Suggested fields:

- `id`: UUID primary key
- `name`: text, required
- `message`: text, required
- `created_at`: timestamptz, server default
- `is_approved`: boolean, optional depending on moderation strategy

## Recommended Constraints

- name length: 1–80 characters
- message length: 1–1000 characters
- name trimmed
- message trimmed
- created_at generated by database

## Moderation Decision

Default recommendation:
Use `is_approved` if you want the couple to moderate wishes before public
display.

If no moderation is required, the API may publish successful submissions
immediately.

Mark this decision in `PROJECT_STATUS.md`.

## Security

- Enable RLS.
- Do not expose secret key to the browser.
- Never trust client-side validation.
- Render messages as text, not HTML.
