# Functional Requirements

## FR-01 Data-driven wedding content
All wedding-specific content must be separated from presentation components.

## FR-02 Countdown
The countdown must calculate remaining time from a configured target datetime.

## FR-03 Calendar
Provide a visual date representation and, if enabled, calendar action.

## FR-04 Maps
Event/venue records may provide a maps URL.

## FR-05 Gallery
Gallery items must be renderable from typed data.

## FR-06 Lightbox
Lightbox must support open, close, next, previous, and accessible controls.

## FR-07 Guestbook GET
Return guestbook wishes according to publication/moderation rules.

## FR-08 Guestbook POST
Validate and persist a new wish.

## FR-09 Guestbook error handling
Do not expose internal database errors or secrets to end users.

## FR-10 Gift copy
Copy account number to clipboard where browser support exists.

## FR-11 SEO
Metadata must be generated from centralized configuration.

## FR-12 Accessibility
Keyboard navigation, focus visibility, semantic structure, labels, alt text,
and reduced motion must be considered.
