# User Journey

## Journey A — First Visit

1. User opens invitation link.
2. Hero loads with elegant entrance.
3. User understands couple identity immediately.
4. User scrolls naturally through invitation story.
5. Date and countdown reinforce anticipation.
6. User reads event details.
7. User browses gallery.
8. User leaves a message.
9. User can inspect wedding gift information.
10. User reaches final thank-you section.

## Navigation Principles

The experience should prioritize natural scrolling.

If navigation is used:
- Keep it minimal.
- Use anchors.
- Do not make the website feel like a SaaS application.
- Mobile navigation must be simple.

## Interaction States

Every interactive feature must consider:
- Default
- Hover where relevant
- Focus
- Active
- Loading
- Success
- Error
- Empty
- Disabled
- Reduced motion

## Guestbook Journey

1. User opens guestbook.
2. Sees existing wishes.
3. Enters name.
4. Enters message.
5. Submits.
6. Sees loading state.
7. On success sees confirmation.
8. New wish appears according to moderation strategy.
9. On failure receives a clear retry message.

## Gallery Journey

1. User sees selected images.
2. User taps/clicks image.
3. Lightbox opens.
4. User can navigate.
5. User can close.
6. Mobile users can use touch-friendly controls.
